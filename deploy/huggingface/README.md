# SiteSense – Retail Expansion Intelligence Platform

Scores every ~10-hectare hexagon of Pune for a chosen retail category, simulates customers to estimate profit as a range,
and explains each recommendation in plain language. Source: https://github.com/Suyashh19/sitesense

Optional secrets (Space → Settings → Variables and secrets): `GEMINI_API_KEY`, `GROQ_API_KEY` or `ANTHROPIC_API_KEY`
for AI-written briefings; without them briefings come from templates.
